# AH 股折溢价策略研究

研究 A 股相对 H 股的溢价，是否与 H 股未来收益有关。项目包含月末信号数据、Python 分组分析代码，以及生成的图表和 HTML 报告。

当前结果未通过原先设定的纯折价因子检验，因此尚未继续构建叠加估值和交易成本的持仓策略。

## 分析内容

- 全样本、金融和非金融：按月末 AH 溢价分成五组，比较未来约 1、3、6 个月收益。
- 行业内分组：对样本中超过 4 只股票的行业分别分析，根据可用月份数量采用五组或四组。
- 周期超额：比较最高溢价组与板块等权收益，在上涨月、下跌月及连续上涨至少 4 个月的阶段观察差异。
- 输出分组收益、最高组减最低组、截面相关系数（IC）、统计检验、PNG 图表和 HTML 报告。

## 快速运行

建议使用 Windows 和 Python 3.10 或更新版本。图表默认使用微软雅黑或黑体字体。

在项目根目录打开终端：

```powershell
python -m pip install -r ".\运行代码\requirements.txt"
python ".\运行代码\运行全部.py"
```

完成后，用浏览器打开 `课题研究结论产出/研究报告.html`。也可以直接打开随项目提供的现成报告。

运行会重新生成 `课题研究结论产出` 中的研究结果。默认入口读取随项目提供的 CSV，不需要数据库或在线数据接口。

## 数据与复现范围

当前信号文件包含 13,337 行、117 个信号日和 196 个 H 股代码，信号日期范围为 2017-01-26 至 2026-09-21。各期限的有效收益样本数不同，尚未完成持有期的收益为空。

溢价越高表示 H 股相对 A 股越便宜。分组使用不复权价格对应的溢价，未来收益使用预先计算的 H 股后复权收益。

本项目可以从随附的信号 CSV 复现统计结果。底层日行情、数据库和数据库连接配置未包含在项目中，因此不能仅凭本仓库从底层行情重新生成信号。请使用 `运行全部.py`；直接运行 `02_纯折价五分组.py` 需要维护者的 MySQL 数据环境及相应本机路径配置。

退出规则表用于记录研究口径。当前信号重建代码在配对窗口结束时截断收益，未完整实现规则表中的换股接续和清仓现金流。

上涨、下跌及连续上涨阶段使用持有期内已经发生的板块收益定义，属于事后分析，不能直接作为信号日可知的交易条件。

更多说明见 [研究思路与数据原则](研究思路与数据原则.md)。
